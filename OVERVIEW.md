# Prompt Enhancer

Prompt Enhancer rewrites a draft in an existing Paseo agent's composer. Quick improvement uses your saved defaults. Advanced lets you choose a scenario, edit its instruction and set a history limit for one request. Goal Improve prepares a `/goal` command for review. You can undo the last replacement; the plugin does not send the rewritten draft to the conversation.

Choose a provider and model configured on the selected host in the plugin settings. The built-in scenarios make text concise, improve readability or clarify it. The initial scenarios include adapted DSH Prompt Enhance and OpenAI prompt-editing strategies and can be edited or removed, and you can add your own, choose a default, and rename or hide each composer button. Their default names are “Prompt Import”, “Prompt Advance” and “Goal Improve”. The `/goal` command requires a compatible target agent, such as Codex with goals enabled.

History limits are measured in characters and default to zero. Goal Improve has an editable instruction and a separate limit and tool-history setting. You can include recent user and assistant messages and optionally tool calls and results. The selected provider receives the draft, instruction and selected history. Claude is recommended for fast rewriting. Enable Fast Claude CLI mode in settings; it requires an authenticated Claude CLI on the selected host and does not use custom Paseo provider commands or environment settings. The plugin disables tools and session persistence for it and requests low effort. With fast mode off, all providers remain available through a background agent with normal permissions; they may be slower and use more tokens. The plugin does not automatically approve permission requests. Agent and provider history may retain this content after a helper is archived.

The manifest declares Paseo 0.16 or later; compatibility with the stable 0.16 release has not been verified. The plugin has been exercised with the 0.16.0-beta.2 host and desktop web and Android clients. Controls were not available in an unsent new-agent draft during testing. Recovery after host interruption and use with a separate remote host have not yet been verified.
